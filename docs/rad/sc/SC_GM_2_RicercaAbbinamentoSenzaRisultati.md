# SC_GM_2: RicercaAbbinamentoSenzaRisultati

**ATTORI:** Operator: Luigi

## Flusso di Eventi

| ATTORE | SISTEMA |
| --- | --- |
| Luigi è un Operator della Fondazione Housing Sociale registrato sulla piattaforma I-Need. Dopo aver effettuato l'accesso, raggiunge la sezione dedicata alle richieste abitative dei Guest per elaborare la richiesta attiva di Sara, che cerca una sistemazione nel quartiere Isola di Milano dal 01/03/2027 al 31/08/2027. |  |
|  | Il sistema mostra l'elenco delle richieste abitative attive presentate dai Guest e, per ciascuna richiesta, il comando «Cerca Host compatibili». |
| Luigi individua la richiesta abitativa di Sara e seleziona il comando «Cerca Host compatibili». |  |
|  | Il sistema verifica la presenza di Host idonei e disponibili che soddisfino le condizioni geografiche, temporali e di disponibilità indicate nella richiesta abitativa di Sara. |
|  | Il sistema rileva che nessun Host soddisfa i vincoli della richiesta di Sara. |
|  | Il sistema mostra a Luigi un messaggio che segnala l'assenza di Host idonei per la richiesta selezionata, mantiene la richiesta di Sara nello stato «Attiva» e mostra il comando «Torna alle richieste». |
| Luigi prende atto dell'impossibilità di procedere con un abbinamento e seleziona il comando «Torna alle richieste» senza inviare alcuna proposta. |  |
|  | Il sistema mostra nuovamente l'elenco delle richieste abitative attive dei Guest. |
