# 3.1.1 Attori del sistema
- Host: utente che mette a disposizione uno spazio abitativo.
- Guest: utente alla ricerca di una sistemazione abitativa.
- Convivente: generalizzazione di Host e Guest.
- Operator: Operatore FHS che supervisiona il processo di coabitazione.
- Admin: amministratore incaricato della gestione e manutenzione della piattaforma.
- Utente Registrato: generalizzazione di Host, Guest, Operator e Admin.
- Utente non Registrato: utente generico che accede all'applicazione o al sito web senza aver effettuato l'autenticazione
