# 4 Glossario

| Termine | Definizione |
| --- | --- |
| Host | Utente che mette a disposizione uno spazio abitativo all'interno del programma di coabitazione solidale. |
| Guest | Utente alla ricerca di una sistemazione abitativa per un determinato periodo. |
| Convivente | Host o Guest coinvolto in un percorso di coabitazione. |
| Operator | Operatore della FHS che supervisiona il processo di coabitazione, dall'abbinamento al monitoraggio delle convivenze. |
| Admin | Amministratore della piattaforma; gestisce gli account degli utenti e crea gli account Operator. |
| Alloggio/Abitazione | Spazio abitativo registrato dall'Host, descritto da area geografica, indirizzo, tipologia e periodo di disponibilità. |
| Area Geografica | Zona identificata da una città e da una zona o quartiere di quella città. |
| Richiesta Abitativa | Richiesta presentata dal Guest che indica l'area geografica e il periodo di permanenza desiderati; il Guest può averne una sola attiva alla volta. |
| Questionario delle Preferenze | Questionario sulle esigenze e abitudini personali compilato da ogni Convivente; viene usato per calcolare la compatibilità. |
| Host Idoneo | Host che soddisfa le condizioni geografiche, temporali e di disponibilità di una Richiesta Abitativa. |
| Punteggio di Compatibilità | Valore calcolato dal sistema confrontando i Questionari delle Preferenze di Host e Guest; ordina gli Host Idonei in una graduatoria. |
| Proposta di Abbinamento | Proposta di coabitazione inviata dall'Operator a un Host e a un Guest; si considera accettata solo se entrambi la accettano. |
| Proposta Pendente | Proposta di Abbinamento ancora in attesa della risposta di almeno una delle parti. |
| Convivenza | Percorso di coabitazione tra un Host e un Guest presso un alloggio, attivato dopo la doppia accettazione della proposta; può essere Attiva o Conclusa. |
| Interruzione Anticipata | Chiusura di una Convivenza prima della data di fine prevista; il Convivente la richiede e l'Operator la registra. |
| Questionario di Gradimento | Questionario compilato da ogni Convivente al termine della Convivenza per valutarne l'esito. |

## 1.4 Definizioni, acronimi e abbreviazioni

Definizioni: Si rimanda alla sezione Glossario per la definizione dei termini di dominio.

Acronimi e abbreviazioni di dominio:
- FHS: Fondazione Housing Sociale
- HOST: Utente che mette a disposizione uno spazio abitativo
- GUEST: Utente alla ricerca di una sistemazione abitativa
- CONV (Convivente): Generalizzazione degli attori direttamente coinvolti in un percorso di coabitazione, che comprende i ruoli di Host e Guest
- OP (Operator): Operatore dell’organizzazione FHS che supervisiona il processo di coabitazione
- ADMIN: Amministratore incaricato della gestione e manutenzione generale della piattaforma
- UR (Utente Registrato): Generalizzazione degli utenti autenticati sulla piattaforma, che comprende Host, Guest, Operator e Admin

Acronimi dei raggruppamenti funzionali (Gestioni):
- GU: Gestione Utente
- GA: Gestione Abitazione
- GR: Gestione Richieste Abitative
- GM: Gestione Matching e Proposte
- GC: Gestione Convivenza e Feedback

Acronimi tecnici e di modellazione:
- PM: Project Managers
- TM: Team Members
- RAD: Requirement Analysis Document (Documento di Analisi dei Requisiti)
- SDD: System Design Document
- ODD: Object Design Document
- RF: Requisito Funzionale
- RNF: Requisito Non Funzionale
- US: User Story
- SC: Scenario
- UC: Use Case (Caso d'Uso)
- UCM: Use Case Model
- CD: Class Diagram
- AD: Activity Diagram (Diagramma delle Attività)
- SCD: StateChart Diagram
- SD: Sequence Diagram
- UI: User Interface (Interfaccia utente / Mock-up)
- NP: Navigation Paths (Percorsi di Navigazione)
- AI: Artificial Intelligence (Intelligenza Artificiale)
- JSON: JavaScript Object Notation
- HTML5: HyperText Markup Language (versione 5)
- CSS: Cascading Style Sheets

Acronimi per i Requisiti Non Funzionali (Modello FURPS+)
- F: Funzionalità
- U: Usabilità
- A: Affidabilità (Reliability)
- P: Prestazioni (Performance)
- S: Sostenibilità (Supportability)

Il "+" indica gli pseudo-requisiti o vincoli del sistema:
  - I: Implementazione
  - IN: Interfaccia
  - O: Operazione
  - PA: Packaging
  - L: Legali
