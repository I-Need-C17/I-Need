# RF_GU: Gestione Utente

| Identificativo | Nome | Descrizione | Attori | Priorità |
| --- | --- | --- | --- | --- |
| RF_GU_1 | Registrazione Host | Il sistema dovrebbe permettere a un Utente non Registrato di registrarsi come Host sulla piattaforma. | Utente non Registrato | Media |
| RF_GU_2 | Registrazione Guest | Il sistema dovrebbe permettere a un Utente non Registrato di registrarsi come Guest sulla piattaforma. | Utente non Registrato | Media |
| RF_GU_3 | Login | Il sistema dovrebbe permettere all'Utente Registrato di accedere al proprio account. | Utente Registrato | Media |
| RF_GU_4 | Logout | Il sistema dovrebbe permettere all'Utente Registrato di disconnettersi dal proprio account. | Utente Registrato | Media |
| RF_GU_5 | Visualizzazione profilo | Il sistema dovrebbe permettere all'Utente Registrato di visualizzare i propri dati personali. | Utente Registrato | Media |
| RF_GU_6 | Modifica dati personali | Il sistema dovrebbe permettere all'Utente Registrato di modificare i propri dati personali. | Utente Registrato | Media |
| RF_GU_7 | Compilazione questionario preferenze Convivente | Il sistema dovrebbe permettere al Convivente di compilare il proprio questionario delle preferenze. | Convivente | Media |
| RF_GU_8 | Visualizzazione questionario preferenze Convivente | Il sistema dovrebbe permettere al Convivente di visualizzare il proprio questionario delle preferenze. | Convivente | Media |
| RF_GU_9 | Modifica questionario preferenze Convivente | Se non sono presenti proposte di abbinamento pendenti, il sistema dovrebbe permettere al Convivente di modificare le risposte del proprio questionario delle preferenze. | Convivente | Media |
| RF_GU_10 | Consultazione profilo Convivente | Il sistema dovrebbe permettere all'Operator di consultare i dati del profilo di un Convivente. | Operator | Media |
| RF_GU_11 | Consultazione questionario Convivente | Il sistema dovrebbe permettere all'Operator di consultare il questionario delle preferenze di un Convivente. | Operator | Media |
| RF_GU_12 | Creazione account Operator | Il sistema può permettere all'Admin di creare un nuovo account Operator. | Admin | Bassa |
| RF_GU_13 | Visualizzazione lista account | Il sistema può permettere all'Admin di visualizzare la lista degli account registrati sulla piattaforma. | Admin | Bassa |
| RF_GU_14 | Disattivazione account utente | Il sistema può permettere all'Admin di disattivare l'account di un utente. | Admin | Bassa |
