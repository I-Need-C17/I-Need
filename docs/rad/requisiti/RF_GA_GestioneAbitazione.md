# RF_GA: Gestione Abitazione

| Identificativo | Nome | Descrizione | Attori | Priorità |
| --- | --- | --- | --- | --- |
| RF_GA_1 | Inserimento abitazione | Il sistema deve permettere all'Host di inserire i dati della propria abitazione e il relativo periodo di disponibilità. | Host | Alta |
| RF_GA_2 | Visualizzazione abitazione | Il sistema dovrebbe permettere all'Host di consultare i dati della propria abitazione. | Host | Media |
| RF_GA_3 | Modifica abitazione | Il sistema dovrebbe permettere all'Host di modificare i dati della propria abitazione e il relativo periodo di disponibilità. | Host | Media |
| RF_GA_4 | Consultazione abitazione Host | Il sistema dovrebbe permettere all'Operator di consultare i dati dell'abitazione associata a un Host. | Operator | Media |
| RF_GA_5 | Consultazione abitazione Host abbinato | Il sistema dovrebbe permettere al Guest abbinato ad un Host di consultare i dati dell'abitazione associata a quell’Host. | Guest | Media |
