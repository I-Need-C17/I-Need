# RF_GM: Gestione Matching e Proposte

| Identificativo | Nome | Descrizione | Attori | Priorità |
| --- | --- | --- | --- | --- |
| RF_GM_1 | Visualizzazione Host Idonei | In presenza di una richiesta abitativa attiva, il sistema deve mostrare all'Operator gli Host Idonei che soddisfano le condizioni geografiche, temporali e di disponibilità della richiesta. | Operator | Alta |
| RF_GM_2 | Visualizzazione punteggio di compatibilità | In presenza di una richiesta abitativa, il sistema deve mostrare all’Operator il punteggio di compatibilità per ogni Host idoneo. | Operator | Alta |
| RF_GM_3 | Invio proposta di abbinamento | Il sistema deve permettere all'Operator di inviare una proposta di abbinamento a un Host e a un Guest che non hanno convivenze attive e che non hanno altre proposte di abbinamento pendenti. | Operator | Alta |
| RF_GM_4 | Annullamento proposta di abbinamento | Il sistema dovrebbe permettere all'Operator di annullare una proposta di abbinamento pendente precedentemente inviata a un Host e a un Guest. | Operator | Media |
| RF_GM_5 | Consultazione proposte ricevute Convivente | Il sistema deve permettere al Convivente di consultare le proposte di abbinamento ricevute. | Convivente | Alta |
| RF_GM_6 | Accettazione proposta Convivente | In presenza di una proposta di abbinamento pendente, il sistema deve permettere al Convivente di accettare tale proposta. | Convivente | Alta |
| RF_GM_7 | Rifiuto proposta Convivente | In presenza di una proposta di abbinamento pendente, il sistema deve permettere al Convivente di rifiutare tale proposta. | Convivente | Alta |
| RF_GM_8 | Consultazione stato proposte | Il sistema dovrebbe permettere all'Operator di consultare lo stato delle proposte di abbinamento inviate. | Operator | Media |
| RF_GM_9 | Consultazione profilo Convivente abbinato | Il sistema deve permettere al Convivente di consultare i dati essenziali e le informazioni sul questionario delle preferenze del Convivente proposto previste per la valutazione della proposta di abbinamento. | Convivente | Alta |
