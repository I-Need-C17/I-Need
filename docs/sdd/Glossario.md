# 1.3 Definizioni, acronimi e abbreviazioni

Le definizioni di dominio e gli acronimi relativi ai requisiti e alla modellazione (FHS, HOST, GUEST, CONV, OP, ADMIN, UR, RF, RNF, UC, SC, CD) sono quelli riportati nel RAD, sezione 1.4. Di seguito si riportano gli ulteriori termini, acronimi e abbreviazioni tecniche utilizzati in questo documento.

## Documentazione e requisiti

- SDD: System Design Document
- RAD: Requirements Analysis Document
- DG: Design Goal

## Architettura e interfacce

- SPA: Single Page Application
- GUI: Graphical User Interface
- API: Application Programming Interface
- REST: Representational State Transfer
- JSON: JavaScript Object Notation
- HTTP(S): HyperText Transfer Protocol (Secure)
- TCP/IP: Transmission Control Protocol / Internet Protocol
- ASGI: Asynchronous Server Gateway Interface

## Sicurezza

- JWT: JSON Web Token
- Persistenza dei dati
- RDBMS: Relational Database Management System
- ACID: Atomicity, Consistency, Isolation, Durability
- JSONB: JSON Binary (formato binario di PostgreSQL per dati JSON)
- JDBC: Java Database Connectivity
- JPA: Jakarta Persistence API
- ORM: Object-Relational Mapping
- CRUD: Create, Read, Update, Delete

## Intelligenza artificiale

- AI: Artificial Intelligence
- NLP: Natural Language Processing

## Infrastruttura e deployment

- VPS: Virtual Private Server
- vCPU: Virtual CPU
- RAM: Random Access Memory
- CPU: Central Processing Unit
- GPU: Graphics Processing Unit
